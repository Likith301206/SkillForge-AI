🚀 SkillForge AI

An AI-powered career development platform built with Flask,Python, and SQLite that helps users build professional resumes,analyze resume quality, and identify skill gaps for different softwarecareers.

✨ Features

👤 User Management

User Registration & Login

Secure Authentication

Profile Management

💡 Skills Management

Add, Edit, Delete, and View Skills

💼 Project Management

Add, Edit, Delete, and View Projects

🏆 Certificate Management

Add, Edit, Delete, and View Certificates

📄 Resume Builder

Create Professional Resume

Resume Preview

Download Resume as PDF

🤖 AI Resume Analyzer

Resume Score

ATS Score

Resume Strengths

Resume Improvement Suggestions

OCR-based Resume Text Extraction

🎯 Skill Gap Analyzer

Supports Python, Java, C++, C#/.NET, JavaScript, Frontend, Backend, FullStack, MERN, and MEAN career paths.

Provides: - Skill Match Percentage - Missing Skills - Learning Roadmap -Recommended Projects - Certifications - Tools - Interview Topics
